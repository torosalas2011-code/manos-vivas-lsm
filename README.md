# Manos Vivas LSM

Crea una app móvil (PWA) de aprendizaje de Lengua de Señas Mexicana (LSM) llamada 'Manos Vivas LSM'. Incluye un diccionario categorizado con buscador y fichas visuales detalladas (abecedario, números, saludos, familia, emergencias), sistema de misiones y retos diarios con niveles progresivos, cuestionarios interactivos de práctica, seguimiento de progreso y rachas, y una interfaz limpia, seria y accesible pensada para pantallas móviles.

This project was built with [Lovable](https://lovable.dev).
