# Referencias visuales para el diccionario LSM

Añadir una ilustración visual consistente a cada seña del catálogo, visible tanto en las tarjetas del diccionario como en su ficha detallada.

## Cambios

- Crear un componente de ilustración de manos con vista de palma/dorso, dedos activos, orientación y flechas de movimiento.
- Definir una configuración visual por seña para las 61 entradas actuales: abecedario, números, saludos, familia y emergencias.
- Mostrar una miniatura clara en cada resultado del diccionario y una versión grande en la ficha individual.
- Conservar el glifo o palabra como apoyo, pero hacer que la postura de manos sea el elemento principal.
- Añadir texto alternativo descriptivo y etiquetas visuales de orientación para accesibilidad.
- Ajustar tamaños y contraste para móvil sin cambiar el progreso, misiones ni cuestionarios.

## Detalles técnicos

- Las ilustraciones serán vectoriales y se generarán dentro de la app, evitando imágenes externas inconsistentes.
- Las señas con movimiento mostrarán flechas o trayectorias; las de dos manos mostrarán ambas manos.
- Se validará la lista y el detalle en pantalla móvil, incluyendo búsqueda, filtros y navegación.
